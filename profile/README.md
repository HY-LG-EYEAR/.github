# EYEAR

**Eyes and Ears for Proactive Smart Home Orchestration through Spatial Awareness and Multi-Agent Collaboration**

Hanyang University · Fall 2026 · CSE406 Software Engineering & ITE351 AI & Applications

EYEAR explores how room-level sensing can help smart-home appliances respond to residents' activities. Camera, microphone, and mmWave observations are combined into a home-wide World Model. Cleaning, Noise, Temperature, and Lighting agents propose actions to a central Home Orchestrator.

The project is under development. The demonstration uses a surrogate sensor Node and simulated appliances inspired by the LG ThinQ ecosystem.
